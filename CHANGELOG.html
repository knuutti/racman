SluMAN v1.0.5

New features

  • Added an autosplitter for Sly 2. The autosplitter uses SlyGolds standards for splitting, and is supported for Any% as well as all the Episode categories.
  • Added autosplitter support for some MTC categories in Sly 3, including the Ultimate Gauntlet. The MTC Autosplitter updates the Game Time in LiveSplit to match the in-game timer value.

    • Bugfixes

    • Fixed a bug that caused SluMAN process running in the background even after closing the program. This issue likely has caused other issues related to reseting the game.
