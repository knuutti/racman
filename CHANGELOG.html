SluMAN v1.0.7

Bugfixes

  • Fixed a bug that caused the Practice Mode pop-up appear constantly when moving right analogue stick (Sly 2).
  • Fixed a bug that made gadget only available with cheat codes unlocked when using the gadget editor (Sly 2).

SluMAN v1.0.6

New features

  • Added a Speedrun Mode for Sly 1 NTSC, including input viewer and autosplitter for Any%.
  • Added Practice Mode for Sly 2 KOR, including job checkpoint and map loading, cutscene skipper and other features similar to Sly 3 Practice Mode.
  • Added an ability to Sly 3 Practice Mode to select a character to load as after a reload.

Bugfixes

  • Fixed a bug that caused the game crashing when loading some job checkpoints in Sly 3.
