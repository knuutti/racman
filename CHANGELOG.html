SluMAN v1.0.0

General

  • Changed backend from RacMAN-EXT to racman, which means major changes in the UI as well as the backend functionality.
  • Support for Sly 2 is temporarily disabled
  • Added automatic updater that checks for new versions when app is launched

Sly 3

  • Added Speedrun Mode that includes input display, memory-based autosplitter and run file loading. Use of Speedrun Mode is allowed during speedruns, however only input display and autosplitter can be actively used while the timer is running.
  • Added autosplitter for Any% category as well as all individual Episode categories
